### 2.2 `engine/CMakeLists.txt` 18줄 — `-sEXPORTED_RUNTIME_METHODS=UTF8ToString`

```cmake
if(EMSCRIPTEN)
  add_executable(engine src/c_api.cpp)
  target_link_libraries(engine PRIVATE trip_engine)
  set_target_properties(engine PROPERTIES SUFFIX ".mjs")
  target_link_options(engine PRIVATE "-sEXPORTED_FUNCTIONS=_trip_optimize,_trip_last_error,_trip_output_size,_malloc,_free" "-sMODULARIZE=1" "-sEXPORT_ES6=1" "-sALLOW_MEMORY_GROWTH=1" "-sENVIRONMENT=web,worker,node" "-sEXPORTED_RUNTIME_METHODS=UTF8ToString")
endif()
```

- `EXPORTED_FUNCTIONS`는 **C 함수**(`_trip_optimize` 등, 앞에 `_`)를 Module 객체에 붙인다. `EXPORTED_RUNTIME_METHODS`는 Emscripten이 JS로 제공하는
  **런타임 도우미**(`UTF8ToString`, `ccall` 등)를 붙인다. 두 목록은 따로다.
- `UTF8ToString(ptr)`: WASM 메모리의 `ptr`부터 0 바이트까지를 UTF-8로 읽어 JS 문자열로 만든다. `_trip_last_error()`가 돌려주는 것은 C 문자열의
  **주소(숫자)**일 뿐이라 이 함수가 있어야 글자가 된다.
- code/03 3.4절은 "옵션이 없으면 `mod.UTF8ToString`이 `undefined`일 것"을 **소스 읽기로만** 판단했다. 이번에는 실제 WASM으로 확인하는 시험이 생겼다:
  error_test의 시험 1은 상태 줄에 엔진 문장 `visits must be`(c_api.cpp 35줄 `"visits must be 1..10, days, modes and k at least 1"`)가 보여야
  통과한다. `UTF8ToString`이 없으면 상태 줄은 `Error during optimization: mod.UTF8ToString is not a function`이 되어 실패한다. `0a9c13d`의 CI에서 이 단계가
  성공했다(4장).

### 2.3 `model.mjs` `callEngine` (273–329줄) — try/finally로 버퍼 6개 해제

```js
export function callEngine(mod, parsed) {
    const p = parsed;
    
    let ptrPrice = 0;
    let ptrMinutes = 0;
    let ptrLodging = 0;
    let ptrStayMin = 0;
    let ptrStayMax = 0;
    let ptrOut = 0;
    
    try {
        ptrPrice = mod._malloc(p.priceArr.length * 8);
        ptrMinutes = mod._malloc(p.minsArr.length * 8);
        ptrLodging = mod._malloc(p.lodgingArr.length * 8);
        ptrStayMin = mod._malloc(p.stayMinArr.length * 4);
        ptrStayMax = mod._malloc(p.stayMaxArr.length * 4);
        
        const out_len = mod._trip_output_size(p.V, p.k);
        if (out_len <= 0) {
            throw new Error("Invalid output size");
        }
        ptrOut = mod._malloc(out_len * 8);
        
        mod.HEAPF64.set(p.priceArr, ptrPrice / 8);
        mod.HEAPF64.set(p.minsArr, ptrMinutes / 8);
        mod.HEAPF64.set(p.lodgingArr, ptrLodging / 8);
        mod.HEAP32.set(p.stayMinArr, ptrStayMin / 4);
        mod.HEAP32.set(p.stayMaxArr, ptrStayMax / 4);
        mod.HEAPF64.fill(0.0, ptrOut / 8, ptrOut / 8 + out_len);
        
        const numPlans = mod._trip_optimize(
            p.V, p.days, p.M,
            ptrPrice, ptrMinutes, ptrLodging,
            ptrStayMin, ptrStayMax,
            p.departMin, p.departMax, p.costPerMinute,
            p.k, ptrOut, out_len
        );
        
        if (numPlans < 0) {
            const errPtr = mod._trip_last_error();
            const errStr = mod.UTF8ToString(errPtr);
            throw new Error(errStr);
        }
        
        const outActual = new Float64Array(mod.HEAPF64.subarray(ptrOut / 8, ptrOut / 8 + out_len));
        const plans = decodePlans(outActual, numPlans, p.k, p.V, p.nodeToCity, p.modeIdxToName, p.startDate);
        
        return plans;
    } finally {
        if (ptrPrice) mod._free(ptrPrice);
        if (ptrMinutes) mod._free(ptrMinutes);
        if (ptrLodging) mod._free(ptrLodging);
        if (ptrStayMin) mod._free(ptrStayMin);
        if (ptrStayMax) mod._free(ptrStayMax);
        if (ptrOut) mod._free(ptrOut);
    }
}
```

### 2.4 `worker.mjs` (27줄) — `init`의 try/catch

```js
import Module from './engine.mjs';
import { callEngine } from './model.mjs';

let modPromise = null;

self.onmessage = async (e) => {
    const data = e.data;
    if (data.type === 'init') {
        try {
            if (!modPromise) {
                modPromise = Module();
            }
            await modPromise;
            self.postMessage({ type: 'ready' });
        } catch (err) {
            self.postMessage({ type: 'error', error: err.message || String(err) });
        }
    } else if (data.type === 'optimize') {
        try {
            const mod = await modPromise;
            const plans = callEngine(mod, data.payload);
            self.postMessage({ type: 'success', numPlans: plans.length, plans });
        } catch (err) {
            self.postMessage({ type: 'error', error: err.message || String(err) });
        }
    }
};
```

- 9–17줄: `Module()`(엔진 적재)이 거부되면 `{ type: 'error', … }`를 보낸다. 예전에는 `await modPromise`가 try 밖이라 처리되지 않은 거부였다.
- **주의(코드가 하는 일 그대로):** 화면의 `onmessage`(index.html 80–81줄)는 `error`를 받으면 `pendingReject`가 있을 때만 쓴다. 페이지가 열리자마자
  보내는 `init`의 시점에는 대기 중인 최적화가 없으므로 `pendingReject`가 `null`이고, **이 오류 메시지는 화면에서 버려진다**. 사용자가 최적화를 누르면
  20줄의 `await modPromise`가 같은 거부를 다시 받아 그때 `Error during optimization: …`이 보인다. 이 경로에서는 `workerDead`도 `true`가 되지 않는다.
- 즉 "워커 파일은 받았는데 `engine.wasm`만 못 받음"(`Module()` 거부)과 "`engine.mjs` 자체를 못 받음"(워커 생성 실패 → `onerror`)은 다른 길이다.
  2.6절의 시험 2는 둘 다 막기 때문에 **뒤의 길만** 지난다(연습 문제 1).
