## 구조 (사용자가 잡은 경계, 2026-10-02)

```
Sensor ─Telemetry─▶ State / DC ─▶ CR(Policy 가 쓸 맥락을 짓는다) ─▶ Policy ─▶ Action Intent ─▶ Validate ─▶ Arbitrate ─▶ Guard ─▶ Executor
                                                  옆: Provider Adapter(캐시 번역) · Runtime Telemetry(토큰 · 캐시 · 꺼냄 · 지연 · 실패)
```

Policy = decision rule · CR = decision context construction rule · Arbitrate = 선택 · Guard = 허가 · 캐시는 CR 의 책임(선언) + 어댑터(번역) · WALP 는 쓰지 않는다.
순서 ①~⑨: ① CR 분리 ✅ · ② Sensor → Telemetry ✅ · ③ Telemetry → DC · ④ DC → CR · ⑤ Policy · ⑥ Action Intent · ⑦ Validate/Arbitrate/Guard · ⑧ Claude Code 그림자 · ⑨ API 평가.
