## 지원 동기
젠틀몬스터(Gentle Monster) LAB이 선보이는 혁신적인 공간 경험과 키네틱 아트 로봇 시스템의 소프트웨어 제어 엔지니어로 기여하고자 지원합니다. Future Artifact에서 Python 기반으로 센서 관측, 상태 추정, 그리고 결정론적 제어 아키텍처를 설계하고 운영한 경험을 보유하고 있습니다. 전시 공간의 로봇은 단순한 반복 구동을 넘어 높은 안정성과 실시간 결함 감지가 요구되는 만큼, 정밀한 관측과 상태 추정, 견고한 제어 분기를 통해 안전하고 독창적인 로봇 모션을 구현하겠습니다.

## 직무 이해
LAB 로봇 소프트웨어 엔지니어 직무는 젠틀몬스터의 리테일 및 전시 공간에 설치되는 키네틱 구조물과 로봇 시스템이 관람객과 상호작용하며 장시간 안정적으로 구동될 수 있도록 제어 소프트웨어를 설계하고 운영하는 핵심 직무입니다. 이는 관측(센서) → 상태 추정(필터링/상태 관리) → 결정(정책 중재/안전 제어) → 행동(모터 및 액추에이터 구동)으로 이어지는 폐루프 제어 아키텍처를 요구하며, 하드웨어 결함이나 예외 상황에서도 시스템이 멈추거나 오작동하지 않도록 결정론적 제어 루프를 보장해야 합니다.

## 핵심 역량
1. Python 기반 5계층 제어 아키텍처 설계:
   Future Artifact에서 Telemetry → Sensor → State → DC → MS로 이어지는 모듈형 5단계 제어 파이프라인을 구축하여 복잡한 시스템의 상태 추정 및 결정 분기를 체계화했습니다.
2. 실행 고리의 토큰 실측과 경량화 (baseline BD-416 · BD-458):
   에이전트가 매 턴 읽는 입력에서 불필요한 도구 정의를 걷어내 턴당 고정 입력을 9,852토큰에서 2,530토큰으로 약 74% 줄였습니다.
3. 결정론적 중재 및 결함 감지 (GA Engine ga judge / router):
   작은 시험 과제에서 모델이 10턴 동안 37,023토큰을 쓰고 실패한 것을 보고 진전 없는 턴을 세는 규칙을 고쳐 3턴에 멈추게 했습니다. 엔진은 새 클론에서 1,347개 시험이 통과하는 상태로 관리합니다.

## 경험 및 프로젝트
1. Future Artifact 제어 아키텍처 (Telemetry → Sensor → State → DC → MS):
   Python 환경에서 원시 텔레메트리 관측 데이터를 센서 계층으로 받아들여 시스템 상태(State)를 추정하고, 결정 맥락(DC, Decision Context)을 거쳐 정책 런타임(MS, LLM Policy Runtime)이 행동을 정하는 완전한 제어 파이프라인을 설계 및 구현했습니다.
2. llmsensor 프로젝트:
   LLM을 하나의 자율 시스템으로 보고 센서 다섯이 판독값(OK · SUSPECT · FAULT · UNKNOWN)을 내며, 잠재 상태 P(success | 증거)를 추정하고 받을지는 결정론적 판정기가 정하는 구조를 연구했습니다(analytical redundancy의 "잔차 생성 → 결정" 두 단계).
3. GA Engine (ga judge 및 router):
   비결정론적 신호나 예외 상황을 감지(Fault Detection)하고 안전한 결정론적 행동으로 유도하는 중재 시스템을 구현하여 1,347개의 테스트를 통과시켰습니다.
