## 개요
본 포트폴리오는 Gentle Monster LAB 로봇 소프트웨어 직무를 위해, 지원자의 기술적 배경을 제어 공학적 프레임워크인 '관측 → 상태 추정 → 결정 → 행동' 관점에서 재해석하여 기술합니다. Future Artifact에서 Python을 기반으로 구축한 센서 최적화, 다계층 상태 관리, 결정론적 중재 시스템의 실측 수치와 아키텍처를 제시하고, 이를 로봇 소프트웨어에 적용하는 방안과 향후 학습 계획을 설명합니다.

## 프로젝트
### 1. llmsensor: LLM에 센서를 다는 상태 추정 연구
- 제어 문제 정의: LLM을 하나의 자율 시스템으로 보고, 그 출력을 믿을지 말지를 LLM이 아닌 결정론적 판정기가 정하도록 하는 감시 문제.
- 제어 루프 구조: 관측(실행 기록) → 상태 추정(센서 다섯의 판독값 OK · SUSPECT · FAULT · UNKNOWN, 잠재 상태 P(success | 증거) 추정) → 결정(결정론적 판정기) → 행동(받음 / 되돌림).
- 근거 방법론: NASA 식 analytical redundancy(Chow & Willsky 1984)의 "잔차 생성 → 결정" 두 단계를 빌림.
- 정량적 측정 결과: [확인 필요 — facts.md에 llmsensor 단독 수치 없음]

### 2. Telemetry → Sensor → State → DC → MS: 다계층 제어 파이프라인
- 제어 문제 정의: 불확실한 외부 입력으로부터 안전하고 결정론적인 시스템 행동을 생성하기 위한 계층적 제어 아키텍처 구축.
- 제어 루프 구조: 관측(Telemetry 계층) → 상태 추정(Sensor 계층 필터링 후 State 계층에서 전역 상태 합성) → 결정(DC, Decision Context: 이번 결정에 필요한 상태를 골라 신선도 · 근거 · 제약을 붙인 고정 스냅숏) → 행동(MS, LLM Policy Runtime: 무엇을 보일지 · 누구에게 물을지 · 제안을 받을지).
- Python 구현 내용: Python을 사용하여 계층 간 관심사를 분리하고 모듈화된 5단계 제어 파이프라인 완성.
- 정량적 측정 결과: [확인 필요 — facts.md에 이 파이프라인 단독 수치 없음]

### 3. GA Engine (ga judge / router): 결정론적 중재 및 결함 감지
- 제어 문제 정의: 다중 정책 및 예외 상황에서 시스템의 오작동을 방지하고 결정론적 안전성을 보장하는 중재 및 결함 감지 문제.
- 제어 루프 구조: 관측(시스템 런타임 이벤트 및 에이전트 출력 관측) → 상태 추정(ga judge를 통한 신뢰도 평가 및 결함 감지, Fault Detection) → 결정(router를 통한 안전한 제어 경로 결정론적 중재, Deterministic Arbitration) → 행동(안전 제어 명령 하달).
- Python 구현 내용: Python 기반 규칙 검증기 및 동적 라우팅 엔진 구현, 자동화 테스트 구축.
- 정량적 측정 결과: 새 클론에서 1,347개 시험 통과 상태로 관리. 모델이 10턴 동안 37,023토큰을 쓰고 실패한 사례를 보고 진전 없는 턴을 세는 규칙을 고쳐 3턴에 멈추게 함. 에이전트 턴당 고정 입력 9,852 → 2,530토큰(약 74% 감소).

## 제어 관점
본 프로젝트들에서 구축한 소프트웨어 아키텍처는 로봇 소프트웨어의 핵심 제어 계층과 다음과 같이 일대일로 대응됩니다:
1. 센싱(Sensing): llmsensor의 '센서 판독값 → 잠재 상태 추정' 구조는 로봇의 카메라, LiDAR, IMU 판독값으로 상태를 추정하는 구조와 개념적으로 닮았습니다.
2. 상태 추정(State Estimation): State 계층의 전역 상태 관리는 로봇 기구학의 관절 각도, 속도, 엔드이펙터 위치를 추정하는 상태 추정과 개념적으로 대응합니다(물리 로봇 경험은 [확인 필요]).
3. 결함 감지(Fault Detection): ga judge가 수행하는 정책 무결성 검증은 로봇 액추에이터의 과부하, 모터 엔코더 오차, 센서 신호 이상을 실시간으로 감지하는 안전 감시 시스템에 대응됩니다.
4. 결정론적 중재(Deterministic Arbitration of a Learned Policy): router 시스템은 비결정론적이거나 학습된 정책(Learned Policy)이 불안정한 명령을 내릴 때 이를 차단하고 결정론적 안전 제어기로 전환하는 안전 중재(Safety Arbitration) 원리와 개념적으로 닮았습니다.
