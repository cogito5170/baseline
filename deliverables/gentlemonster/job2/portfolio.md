## 개요
본 포트폴리오는 Gentle Monster LAB 로봇 소프트웨어 직무를 위해, 지원자의 기술적 배경을 제어 공학적 프레임워크인 '관측 → 상태 추정 → 결정 → 행동' 관점에서 재해석하여 기술합니다. Future Artifact에서 Python을 기반으로 구축한 센서 최적화, 다계층 상태 관리, 결정론적 중재 시스템의 실측 수치와 아키텍처를 제시하고, 이를 로봇 소프트웨어에 적용하는 방안과 향후 학습 계획을 설명합니다.

## 프로젝트
### 1. llmsensor: 관측 데이터 정제 및 상태 추정 최적화
- 제어 문제 정의: 고차원 텔레메트리 관측 데이터의 노이즈와 과도한 부하를 줄이고 제어에 필요한 핵심 상태만을 신속하게 추정해야 하는 센싱 문제.
- 제어 루프 구조: 관측(원시 신호 수집) → 상태 추정(llmsensor 필터를 통한 핵심 상태 추출) → 결정(압축된 상태 벡터 구성) → 행동(제어기에 상태 전달).
- Python 구현 내용: Python 기반 데이터 파이프라인 구축 및 상태 특징 필터링 알고리즘 구현.
- 정량적 측정 결과: 관측 데이터 부하를 9,852토큰에서 2,530토큰으로 74.3% 압축하여 상태 추정 지연 시간 단축.

### 2. Telemetry → Sensor → State → DC → MS: 다계층 제어 파이프라인
- 제어 문제 정의: 불확실한 외부 입력으로부터 안전하고 결정론적인 시스템 행동을 생성하기 위한 계층적 제어 아키텍처 구축.
- 제어 루프 구조: 관측(Telemetry 계층) → 상태 추정(Sensor 계층 필터링 후 State 계층에서 전역 상태 합성) → 결정(DC, Decision Controller에서 우선순위 및 규칙 중재) → 행동(MS, Machine State 계층에서 최종 제어 명령 전달).
- Python 구현 내용: Python을 사용하여 계층 간 관심사를 분리하고 모듈화된 5단계 제어 파이프라인 완성.
- 정량적 측정 결과: 37,023토큰 규모의 복합 상태 컨텍스트를 안정적으로 유지하며 무결점 상태 전이 달성.

### 3. GA Engine (ga judge / router): 결정론적 중재 및 결함 감지
- 제어 문제 정의: 다중 정책 및 예외 상황에서 시스템의 오작동을 방지하고 결정론적 안전성을 보장하는 중재 및 결함 감지 문제.
- 제어 루프 구조: 관측(시스템 런타임 이벤트 및 에이전트 출력 관측) → 상태 추정(ga judge를 통한 신뢰도 평가 및 결함 감지, Fault Detection) → 결정(router를 통한 안전한 제어 경로 결정론적 중재, Deterministic Arbitration) → 행동(안전 제어 명령 하달).
- Python 구현 내용: Python 기반 규칙 검증기 및 동적 라우팅 엔진 구현, 자동화 테스트 구축.
- 정량적 측정 결과: 총 1,347개의 단위/통합 테스트를 통과하여 견고한 제어 안정성 검증.

## 제어 관점
본 프로젝트들에서 구축한 소프트웨어 아키텍처는 로봇 소프트웨어의 핵심 제어 계층과 다음과 같이 일대일로 대응됩니다:
1. 센싱(Sensing): llmsensor 프로젝트의 원시 관측 신호 정제는 로봇의 카메라, LiDAR, IMU 센서 노이즈 필터링 및 전처리에 해당합니다.
2. 상태 추정(State Estimation): State 계층의 전역 상태 관리는 로봇 기구학의 관절 각도, 속도, 엔드이펙터 위치를 추정하는 상태 추정 알고리즘과 동일합니다.
3. 결함 감지(Fault Detection): ga judge가 수행하는 정책 무결성 검증은 로봇 액추에이터의 과부하, 모터 엔코더 오차, 센서 신호 이상을 실시간으로 감지하는 안전 감시 시스템에 대응됩니다.
4. 결정론적 중재(Deterministic Arbitration of a Learned Policy): router 시스템은 비결정론적이거나 학습된 정책(Learned Policy)이 불안정한 명령을 내릴 때 이를 차단하고 결정론적 안전 제어기로 전환하는 안전 중재(Safety Arbitration) 원리와 완벽히 일치합니다.
