# AI Experience 포트폴리오 에세이 및 프로젝트 기술서

## 1. 무엇이며, 왜 주목했는가
최근 6개월 동안 직접 집중적으로 사용하고 실험한 AI 기술은 Antigravity CLI 기반의 '여러 모델을 한 고리로 묶는 에이전트형 코딩 (도구 없는 에이전트 · 모델 라우팅)'이다.
기존의 AI 활용 방식은 단일 거대 모델(LLM)에 모든 판단과 실행을 위임하거나, 복잡한 도구 호출(Tool Calling)에 의존하여 지연 시간과 비용이 기하급수적으로 증가하는 문제가 있었다. 이에 반해 모델 라우팅과 도구 없는 경량 에이전트 구조는 문제의 성격에 맞춰 적재적소의 모델(Gemini, Claude, GPT-OSS 등)을 배치하고, 정형화된 프로토콜 안에서 모델이 오직 본질적인 판단과 생성에만 집중하게 만든다. 기술의 외형적 환상에 매몰되지 않고, 실제 인터페이스와 시스템 속에서 비용·속도·품질을 엄밀하게 통제하며 새로운 경험을 창출할 수 있는 구조라는 점에서 깊이 주목했다.

## 2. 직접 사용하며 발견한 가능성과 한계
직접 시스템을 설계하고 운영하며 확인한 가능성과 한계는 다음과 같다.

- 가능성:
작은 모델이라도 정해진 양식(protocol)이 주어지면 놀라운 효율성을 발휘한다. 실제로 gpt-oss-120b-medium과 같은 작은 모델이 명확한 규격 안에서 단 1턴, 약 4,7xx 토큰만으로 리포트 화면 한 장을 완벽하게 구현해냈다(AGA5 · AGA6). 복잡한 다중 에이전트 도구를 걷어내고 작업 목적에 맞는 경량 카드를 제공했을 때 초저지연과 일관된 품질을 확보할 수 있음을 확인했다.

- 한계:
첫째, 기본 설정 에이전트의 막대한 고정 비용이다. 기본 에이전트 환경에서는 턴당 고정 입력만 9,852 토큰에 달해 연산 자원과 응답 시간이 낭비되었다. 이를 해결하기 위해 도구 없는 에이전트로 전환하여 입력을 2,530–2,958 토큰으로 대폭 감축했다.
둘째, 정확한 문자열 편집에 대한 취약성과 진전 없는 반복이다. 작은 시험 과제에서 모델이 10턴 동안 무려 37,023 토큰을 소모하면서도 동일한 실수를 되풀이하며 실패하는 현상을 관측했다. 모델 자체의 자기 수정 능력에만 의존할 수 없다는 한계를 파악하고, 진전 없는 턴을 감지하여 3턴 안에 작업을 강제 중단시키는 결정론적 규칙을 엔진에 도입함으로써 한계를 극복했다.

## 3. 사람의 행동이나 경험을 어떻게 바꿀까
기존의 AI 인터페이스는 사용자가 챗봇 입력창에 텍스트를 치고 기다리는 지루하고 평면적인 행동 양식에 머물러 있었다. 그러나 다중 모델 라우팅과 경량 에이전트 고리가 일상 환경과 결합되면 인간의 경험은 '질의응답'에서 '감각적 공명'으로 진화한다.
사용자가 별도의 프롬프트를 고민할 필요 없이, 시스템이 사용자의 환경과 행동 맥락을 실시간 관측(Telemetry)하고 상태를 추정하여 가장 적합한 모델이 즉각적인 시각·공간적 반응을 생성한다. 대기 시간 없는 즉각적인 피드백과 군더더기 없는 미니멀 인터페이스는 사용자가 기계를 조작하고 있다는 의식조차 잊게 만들며, 인간의 시각과 신체 감각이 기술과 자연스럽게 동기화되는 새로운 사용자 경험을 제공하게 될 것이다.

## 4. 패션 또는 브랜드와 연결한 새로운 가능성
젠틀몬스터는 공간의 공감각적 충격과 아방가르드한 아이웨어 오브제로 독보적인 브랜드 세계관을 구축해왔다. 모델 라우팅 및 제어 고리 기술을 젠틀몬스터에 결합하여 공간(Space), 오브제(Object), 디지털(Digital)이 유기적으로 호흡하는 '자율 반응형 키네틱 플래그십 (Autonomous Kinetic Flagship)' 경험을 제안한다.

- 공간 (Space):
성수 플래그십 매장에 들어서는 고객의 동선과 체류 시간, 시선 데이터를 매장 내 L0 Telemetry 센서가 비간섭 방식으로 감지한다.
- 오브제 (Object):
공간 중심에 배치된 거대한 젠틀몬스터 키네틱 인스톨레이션(로보틱스 아이웨어 조형물)이 방문객 집단의 밀집도와 움직임 스냅숏(L3 DC)에 반응하여 기계 관절의 움직임 주기와 조명 조도를 실시간으로 변형한다.
- 디지털 (Digital):
매장 내 인터랙티브 미러 디스플레이에 다크·흑백·미니멀 인터페이스가 작동한다. 2 KB 이하의 경량 판단 카드로 모델 라우터가 방문객의 스타일과 시선을 1턴 만에 판정하여, 가장 어울리는 아이웨어 3D 렌더링과 개인화 룩북을 4,7xx 토큰 수준의 초경량 비용과 실시간 속도로 거울 표면에 투사한다.

정적인 디스플레이를 넘어 공간과 오브제, 디지털 인터페이스가 살아있는 유기체처럼 방문객과 상호작용하는 전례 없는 브랜드 경험을 선사할 수 있다.

## 프로젝트
1. GA Console:
- 디자인 원칙: "장식·표시용 정적인 선은 없애고, 기능을 나타내는 선과 실시간으로 움직이는 레이아웃은 남긴다"
- 로컬 웹 콘솔. 다크 · 흑백 · 미니멀 스타일 인터페이스. Enter 키 전송 인터랙션 및 토큰 사용량 실시간 시각화. Oracle 클라우드 VM에서 24시간 가동되며 외부에서는 SSH 터널로만 연결되는 보안 환경 구축.
2. Token (ga Console 제품):
- AI 사용 기록을 수집하여 토큰 · 비용 · 품질을 직관적으로 시각화하고, 견적 산출 · 비용 절약 조언 · 개인화 추천을 제공하는 로컬 서비스.
- 리포트 화면 한 장을 작은 모델(gpt-oss-120b-medium)이 1턴, 약 4,7xx 토큰으로 구현(Token, AGA5 · AGA6).
3. GA Engine (ga-sdk 0.17.0):
- 단일 허브 세션이 지시(directive)와 보고(report) 양식으로 다수의 작업 세션을 제어하는 파이프라인 엔진. Python 표준 라이브러리 기반.
- 새 클론 환경에서 1,347개 시험이 무결하게 통과하는 상태 관리.
- ga judge (변이 mutation 기반 판정 재검증), ga hub (6 KB 이하 판정 카드 + 작은 모델 1턴 판단), ga act (EDIT · NEW · RUN 정형 양식 기반 실행), 모델 라우터 (2 KB 이하 카드 판단, 3턴 포기 규칙).
4. 토큰 실측 및 가드레일 최적화:
- agy 기본 에이전트의 턴당 고정 입력 9,852 토큰 → 도구 없는 에이전트로 2,530–2,958 토큰 감축.
- 작은 시험 과제에서 10턴 동안 37,023 토큰을 소모하며 진전 없던 실패 사례를 분석하여 3턴 내 강제 중단 가드레일 확립.
5. llmsensor & 계층 제어 아키텍처:
- LLM을 하나의 자율 시스템으로 규정하고 NASA analytical redundancy(Chow & Willsky 1984) 원리를 적용.
- 5개 센서 판독값(OK · SUSPECT · FAULT · UNKNOWN)과 P(success | 증거) 추정, 결정론적 판정기 구축.
- L0 Telemetry(관측) → L1 Sensor(의미) → L2 State → L3 DC(결정 맥락 고정 스냅숏) → MS(LLM Policy Runtime) 제어 루프.
6. 다중 모델 인프라 운영:
- Oracle 클라우드 VM(x86_64, 2코어)에서 Antigravity CLI(agy)로 18개 모델(Gemini 3.x Flash · Pro, Claude Sonnet · Opus 5.5, GPT-OSS 120B) 오케스트레이션.
- git 우편함을 통한 세션 간 비동기 통신 및 30분 주기 자율 갱신 파이프라인 관리.
