# [GENTLE MONSTER] AI Experience 기획/디자인 담당자 입사지원서

## 지원 동기
젠틀몬스터 AI Experience 파트는 기술과 문화의 변화 속에서 공간, 오브제, 디지털 콘텐츠를 넘나들며 브랜드의 미래 경험을 창조하는 조직입니다. 저는 생성형 AI를 단순히 결과물 제작용 도구로 소비하는 데 머물지 않고, 기술의 내부 제어 구조와 인터페이스 미학을 직접 설계해왔습니다.
로컬 웹 콘솔인 GA Console을 설계하며 "장식·표시용 정적인 선은 없애고, 기능을 나타내는 선과 실시간으로 움직이는 레이아웃은 남긴다"는 확고한 디자인 원칙을 구현했고, AI 사용 기록을 시각화·개인화하는 Token 서비스를 기획했습니다. 또한 18개 모델(Gemini 3.x Flash·Pro, Claude Sonnet·Opus 5.5, GPT-OSS 120B)을 오케스트레이션하고 9,852 토큰에 달하던 입력 비용을 2,530–2,958 토큰으로 최적화하는 등 기술의 본질적 한계를 제어 가능한 경험으로 바꾸는 작업을 지속해왔습니다. 이러한 탐색과 제작 역량을 바탕으로, 젠틀몬스터에서 온·오프라인의 경계를 허무는 독보적인 AI Experience를 구현하고자 지원합니다.

## 직무 이해
AI Experience 기획/디자인 담당자는 기술을 기능적 구현에 한정하지 않고 디자인, 미학, 문화, 인간의 감각이라는 관점에서 재해석하는 직무입니다. 단순히 프롬프트로 비주얼을 뽑아내는 AI 오퍼레이터나 백엔드 개발자가 아니라, AI 디바이스와 새로운 인터페이스가 가져올 기술·문화·사용자 경험의 변화를 읽어내어 프로토타입과 실제 프로젝트로 발전시키는 기획자이자 디자이너입니다.
특히 AI의 환각, 지연 시간, 반복 실패 같은 불확실성을 이해하고 이를 미학적 가이드라인과 결합하여, 젠틀몬스터 플래그십 공간과 오브제, 디지털 환경에서 고객이 마주할 충격적이고 감각적인 경험으로 번역해내는 통찰이 요구됩니다.

## 핵심 역량
1. 미학 원칙에 기반한 인터페이스 및 경험 기획:
GA Console을 설계하며 다크·흑백·미니멀 기조 아래 "장식·표시용 정적인 선은 없애고, 기능을 나타내는 선과 실시간으로 움직이는 레이아웃은 남긴다"는 디자인 철학을 확립했습니다. 정보의 군더더기를 덜어내고 실시간 데이터의 흐름 자체를 조형 언어로 활용하는 감각을 검증했습니다.
2. AI 시스템 제어 및 계층 아키텍처 설계:
NASA analytical redundancy(Chow & Willsky 1984) 원리를 차용해 LLM을 자율 시스템으로 다루는 llmsensor를 연구했습니다. 5개 센서(OK · SUSPECT · FAULT · UNKNOWN) 판독값과 결정론적 판정기를 결합하고, L0 Telemetry(관측) → L1 Sensor(해석) → L2 State → L3 DC(결정 맥락 스냅숏) → MS(LLM Policy Runtime)로 이어지는 엄격한 제어 고리를 Python 표준 라이브러리만으로 완성했습니다.
3. 실측 기반의 모델 오케스트레이션 및 최적화:
Oracle 클라우드 VM(x86_64, 2코어)에서 Antigravity CLI로 18개 모델을 운영하며, 에이전트 턴당 고정 입력을 9,852 토큰에서 도구 없는 에이전트로 2,530–2,958 토큰으로 경량화했습니다. 또한 10턴 동안 37,023 토큰을 낭비하며 실패하던 반복 문제를 분석하여 3턴 중단 가드레일을 구축하는 등 기술의 실용적 한계를 시스템적으로 통제합니다.

## 경험 및 프로젝트
1. GA Engine (ga-sdk 0.17.0) 개발 및 품질 보증:
- 단일 허브 세션이 지시(directive)와 보고(report) 양식으로 다수의 작업 세션을 조율하는 기계적 실행 엔진 구축 (Python 표준 라이브러리 기반).
- 신규 클론 환경에서 1,347개 시험이 모두 통과하는 신뢰성 확보.
- ga judge(변이 mutation 기반 판정 재검증), ga hub(6 KB 이하 판정 카드 + 작은 모델 1턴 판단), ga act(EDIT · NEW · RUN 정형 양식 실행), 모델 라우터(2 KB 이하 카드 판단, 3턴 포기 규칙) 구현.
2. 토큰 실측 및 모델 라우팅 최적화:
- agy 기본 에이전트의 턴당 고정 입력 9,852 토큰을 도구 없는 에이전트로 2,530–2,958 토큰으로 절감.
- 리포트 화면 한 장을 작은 모델(gpt-oss-120b-medium) 1턴, 약 4,7xx 토큰으로 구현(Token, AGA5 · AGA6).
- 10턴 동안 37,023 토큰을 소모하며 진전 없던 실패 사례를 분석하여 3턴 이내 중단 규칙 확립.
3. GA Console 및 Token 서비스:
- 다크·흑백·미니멀 톤의 로컬 웹 콘솔(GA Console) 기획 및 화면 개발. Enter 전송 인터랙션 및 토큰 사용량 실시간 시각화 구현. Oracle VM 24시간 가동 및 SSH 터널 기반 보안 접속 환경 운영.
- AI 사용 기록을 받아 토큰, 비용, 품질을 시각화하고 견적, 절약 조언, 개인화를 제공하는 서비스 'Token' 기획.
4. 다중 모델 인프라 운영:
- Oracle 클라우드 VM(x86_64, 2코어)에서 Antigravity CLI(agy)를 활용해 18개 모델(Gemini 3.x Flash·Pro, Claude Sonnet·Opus 5.5, GPT-OSS 120B) 오케스트레이션.
- 세션 간 통신을 git 우편함으로 동기화하고 30분 주기 자율 갱신 파이프라인 관리.

## 입사 후 계획
1. 시용계약 기간 (3개월):
- 젠틀몬스터의 브랜드 미학, 키네틱 인스톨레이션, 공간 연출 문법을 집중 분석.
- 도구 없는 에이전트 및 모델 라우팅 체계를 접목하여 매장 방문객의 반응과 맥락 데이터를 실시간 처리하는 AI Experience 프로토타입 1차 가설 검증.
2. 중장기 계획:
- 플래그십 스토어의 키네틱 오브제와 디지털 사이니지에 L0 Telemetry ~ MS 계층 제어 고리를 연결하여, 관람객의 움직임과 감각에 실시간으로 반응하는 공간 인터랙션 프로젝트 전개.
- 18개 모델 운영 및 토큰 최적화 경험(9,852 → 2,530 토큰)을 활용하여 초저지연·고감각의 젠틀몬스터 전용 온·오프라인 옴니채널 인터페이스 구축.
